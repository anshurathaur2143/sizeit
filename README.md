SizeIt prototype
=================
This is a first, browser-based image compressor prototype.

How to run:
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, Safari).
3. Upload JPG/PNG/WebP, choose a target KB size and output format, then click Compress Image.

Notes:
- Images are processed in the browser; there is no upload backend.
- PDF compression is not included in this first prototype.
- Exact target sizes cannot be guaranteed for every file/format; the UI reports if the target was not reached.
- Before public launch, test on mobile devices and improve accessibility, quality handling, error states, SEO, and branding.
